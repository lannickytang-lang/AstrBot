## 编写原则（为什么这样写）

1. **分块自包含**：知识库按段落切块后做向量检索，模型只看到命中的几个分块，
   所以每个小节都重复写明"项目名 + 价格 + 关键规则"，不出现"同上""它的价格"等跨段指代。
2. **问法对齐**：FAQ 用顾客的原话式提问作为问题（如"钢琴课多少钱一节"），提高检索召回率。
3. **数字精确**：价格、折扣、预约提前时长、有效期、退款规则均按截图原文写死，机器人不自由发挥。
4. **信息边界**：截图里没有的信息（地址、电话、营业时间、正课价格等）在 06 号文档中明确标注
   "未收录，引导到店咨询"，防止模型编造。
5. **别名覆盖**：笛子→竹笛、萨克斯风→萨克斯、Ukulele→尤克里里、低音吉他→贝斯等，
   在文中用括号并列写出，保证不同叫法都能召回。
6. **时效标注**：全部价格注明"截至 2026-10、以下单页实时为准"。
